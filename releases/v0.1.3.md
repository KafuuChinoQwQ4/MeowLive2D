下载 `MeowLive2D_0.1.3_x64-setup.exe`，按安装向导选择目录并安装。

本版更新：
- 增加独立运行日志页面，支持筛选、自动刷新，最多查看最新 1000 条。
- 精简界面提示，统一人物卡与 LLM 配置下拉框样式，调整人物卡字数统计位置。
- 重写使用指南与 README，区分 Windows 安装版和源码版的环境准备步骤。
- 加入 Linux 自动检查、Windows 原生构建和标签发布流程；附件提供 SHA256 校验和与构建信息。

打开 App 后自动启动内置主服务和桌面执行端。安装包不包含 TTS 引擎、模型、VTube Studio、OBS 或数据库，也不会自动安装 WSL、Docker。观众存储默认关闭；按应用内数据库指引准备后启用。Windows 内置主服务暂不支持本地声音训练，需要连接 Linux / WSL 主服务。

配置保存在 `%APPDATA%\io.meowlive.desktop\`，升级保留已有配置。缺少 WebView2 时安装器会联网下载。此预览版未签名；自动检查与构建不等于真实音频、VTS、OBS 和直播联动的实机验收。


本版还修复了 Windows 路径大小写和长路径前缀导致的配置测试不稳定问题。
